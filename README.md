# Zone-X-Financial-Performance-Product-Profitability-
This project takes a messy two-year sales ledger for Zone X, a business selling two products (Asobe Shirt and Zen T-Shirt), and turns it into a clean dataset, a set of PivotTables and two interactive Excel dashboards. The analysis compares 2024 and 2025 to explain why profit grew by about 20% while revenue grew by only about 2%.
